# A/B Testing for Landing Page Optimization

## Overview
This project analyzes whether a **new landing page improves user conversion rates** compared to the existing page using **A/B testing**. The dataset contains ~294K user sessions with information about page versions and conversion outcomes.

## Methodology
- Performed **data exploration and conversion rate analysis** for control and treatment groups.
- Applied **Two-Proportion Z-Test** to determine if the difference in conversion rates is statistically significant.
- Visualized results using **Matplotlib and Seaborn**.

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Statsmodels

## Goal
Provide **data-driven insights** to determine whether the **new landing page should replace the old page** based on statistical evidence.
